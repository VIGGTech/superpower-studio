Windows Background Service (Optional) checking…
Registers a hidden Windows logon background task (SuperpowersStudioBackground) — zero admin/UAC required — so Studio starts silently in the background when you sign in to Windows and keeps running even if you close terminals or Antigravity.

Creates a native Superpowers Studio shortcut icon that silently starts Studio in the background (if not already running) and opens your browser directly to the dashboard.
